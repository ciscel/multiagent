# 2-Minute Demo — Timed Script

Record as screen capture (admin panel + customer portal visible) with
voiceover. Hard limit: 2:00. Practice against a timer once before recording
— the intro is the part most likely to run long.

| Time | Screen | Say |
|---|---|---|
| 0:00–0:20 | BSOD → Chrome dinosaur → Fail Whale (quick cuts, ~5-6 sec each) | "Windows had a memory error so common it became a meme — then memory protection shipped, and it disappeared. Chrome's offline dinosaur. Twitter's Fail Whale. None of these three tell you what to do. If something's truly agentic, it doesn't display the error better — it retires it. Today, we retire 404." |
| 0:20–0:30 | Title card / app open | "This isn't three products. It's one box. An L1 tech-support agent, a network security system, a compliance tool — one engine, zero internet required." |
| 0:30–0:40 | (stay on title or cut to admin panel) | "Lemma built their company to catch agents that fail silently. Ours never does — every verdict cites the exact rule that made it." |
| 0:40–0:50 | Click **Carrier Outage**, show customer portal update | "38% of ISP support calls start with 'no internet.' Watch — no call, no hold music. It already knows: outage's upstream, no truck roll." |
| 0:50–0:58 | Click **Local Glitch** | "Here it doesn't just diagnose — it fixes it. Auto-remediated, customer told." |
| 0:58–1:08 | Click **Hardware Fault** | "This is the one case that actually needs a technician — and that's the point. The box tells the difference. Most support flows can't." |
| 1:08–1:18 | Click **Neighbor Relay Available** | "No internet, no cellular. If a neighboring unit's reachable, status relays peer to peer. No uplink of its own required." |
| 1:18–1:30 | Click **Security Anomaly** | "Same engine, different question — an unrecognized device shows up, matches a known attack pattern, gets isolated automatically." |
| 1:30–1:48 | Click **View OSCAL Evidence Export**, scroll the JSON | "And here's the third piece. Every event — connectivity, security — lands in one structured, cited evidence trail. Not a dashboard. Something a business hands straight to their insurer." |
| 1:48–2:00 | Back to title card / logo | "Support agent. Security system. Compliance tool. One box, one loop, never needs a connection. If something's truly agentic, it has to retire an error code. Today, we say goodbye to 404." |

## Recording notes

- Cut the error-screen montage to real speed — don't linger, they're
  recognition beats, not analysis. 20 seconds for all three is enough.
- The Lemma line (0:30–0:40) can be voiceover over a static screen if you
  need the visual breathing room — it doesn't need its own footage.
- If you're over time after a practice run, cut **Neighbor Relay Available**
  first (1:08–1:18) — it's the least load-bearing scenario for the judging
  rubric (technical execution + reliability matter more than this one beat).
- Full six-scenario walkthrough with no time limit is in `demo_speech.md` —
  use that version for live Q&A if a judge asks you to go deeper after
  the timed demo.
